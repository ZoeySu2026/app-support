起重機特訓 — 支援與常見問題

題庫依據什麼？

整理自公開之學科測試參考資料。解析為自製內容，說明「為什麼這個對、你選的那個錯在哪」。

本 App 為非官方學習工具，如與主管機關最新公告不符，一律以官方公告為準。

免費可以用到什麼程度？

術科「工作項目01」整章免費，含完整解析；模擬考可免費試考一次。解鎖後開放全題庫解析與無限次模擬考。

付了錢卻沒解鎖

先確認網路正常，然後到「我的 → 還原購買」。若仍未恢復，請來信並附上購買收據。

換手機之後進度不見了

學習紀錄只存在裝置本機，重裝或換機不會轉移。但「完整解鎖」是跟著你的 Apple ID 的，在新裝置點「還原購買」即可恢復，不需再付一次。

購買頁顯示「取得價格中」

表示暫時連不上 App Store。確認網路後按「重新取得價格」。

有術科教學嗎？

沒有。本 App 只處理學科測試。術科需要實機操作與場地練習，請依受訓單位安排。

怎麼設定考試提醒？

「我的 → 考試日」開啟並選日期，會在考前 7 天、3 天與當天早上各提醒一次，並依剩餘天數算出每天建議做幾題。

字太小看不清楚

題目與解析會跟著系統字級調整。到「設定 → 螢幕顯示與亮度 → 文字大小」調大即可。
